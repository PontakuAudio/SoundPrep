# SoundPrep 0.11.8 — ReaPack installation and license guides

Install SoundPrep through ReaPack, restart REAPER, then run **SoundPrep.lua** from the Main Action List. New installations still register only this launcher; additional keyboard and maintenance actions are optional.

- Updated the README and detailed installation guide, including dependencies, startup, updates, optional actions and troubleshooting.
- Added a Japanese guide to the project's MIT License and reorganized third-party attributions. The original license texts, copyright notices and license terms are unchanged.
- Stopped generating manual-install ZIPs for new releases. Earlier release assets remain available. ReaPack continues to install the scripts, resources, license notices and native helper together.

This is a documentation and distribution update. Runtime behavior is unchanged, and the verified native helper remains **0.11.6** on macOS and Windows. Quit SoundPrep before synchronizing ReaPack packages, then start it again. Restart REAPER if it requests a restart or installs/replaces the helper.
