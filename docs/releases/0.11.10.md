SoundPrep 0.11.10

Windowsで素材を選んでから音が出るまでの待ち時間を短くしました。終了後にMedia Explorerの音量や自動再生の設定が変わってしまう問題も修正しています。

変更点

- Windowsのファイル一覧で選んだ素材を、より早く試聴できるようにしました。続けて別の素材を選んだ場合は、最後の選択を再生します。
- 多くのFXを使うPresetでも素材を切り替えやすいよう、使っていないPresetのFXを初期化するタイミングを見直しました。前の素材の残響を止め、次にそのPresetを使う前に初期化します。
- SoundPrepをQuitしたとき、Media Explorerの音量と自動再生を起動前の状態に戻します。古い復旧データが残っている場合や、波形表示モードを変更した場合にも対応しました。
- Windowsで複数のREAPERを開いている場合に、別のREAPERのMedia Explorerを操作してしまう問題を修正しました。
- チャンネル波形を表示しているときの描画負荷を軽くしました。再生カーソルが動くたびに波形全体を描き直さず、必要な部分を更新します。
- ReaPackの変更履歴から、このリリースノートを読めるようにしました。

更新方法

SoundPrepをQuitし、ReaPackの「Synchronize packages」で更新してください。今回はWindows・macOSともにNative helperを0.11.10へ更新します。作業を保存してREAPERを完全に終了し、再起動してからSoundPrep.luaを実行してください。

保存したPresetと設定は引き続き使えます。起動用ActionはSoundPrep.luaです。追加のショートカットが必要な場合だけ、SoundPrep - Install actions.luaを実行してください。

English

- Preview starts sooner when selecting files in the Windows file list. Rapid changes follow the last selected file.
- Unused presets now wait until they are needed to reset their FX buffers. Audio left from the previous file is muted immediately.
- Quitting SoundPrep restores Media Explorer's volume and autoplay to their values at startup, including when stale recovery data is present or the waveform display mode has changed.
- On Windows, SoundPrep uses the Media Explorer belonging to the current REAPER instance.
- Channel waveforms redraw only the area needed to move the playback cursor, reducing drawing work during playback.
- These notes are now included in ReaPack's changelog.

Quit SoundPrep, synchronize packages in ReaPack, then save your work and fully restart REAPER. Both the Windows and macOS native helpers are updated to 0.11.10. Run SoundPrep.lua after restarting. Your saved presets and settings are kept.
