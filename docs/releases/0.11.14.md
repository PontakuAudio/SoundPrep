## SoundPrep 0.11.14

An upkeep release for the native helper: it now updates itself, waveform peaks finish building at selection, and the Windows native windows finally match REAPER.

- **The native helper updates itself**: when a SoundPrep update brings a newer helper, launching SoundPrep now swaps it in automatically and asks you to restart REAPER, the same flow as other ReaPack extensions. No more copying the DLL/dylib by hand; if the swap is not possible, SoundPrep falls back to the manual instructions. This release requires the new helper, and the automatic update handles it - just restart REAPER when asked.
- **Waveform peaks are ready at selection**: for typical sources (up to about two minutes of stereo, longer in proportion for fewer channels), peaks now build to completion as soon as you select the file, instead of finishing partway into playback. Longer and multichannel sources get a large head start and complete moments later.
- **Windows windows match REAPER**: the bar, App Settings, Microphones and Preset Editor windows now all use the classic dialog surface REAPER itself uses, so backgrounds no longer differ between a window, its tabs and its text. This replaces the 0.11.13 unification, which did not fully take on Windows.
