SoundPrep 0.11.19

The preset editor has been reorganized into three pages: Sound, Normalize and Manage. The Export tail setting moved to the Sound page, Analyse moved to the Normalize page, and the preset name field now sits at the top of the Manage page. The bar's Edit button is now called Preset…

Removed the Action slots. The ten SoundPrep - Slot N actions are gone, and presets in the bar no longer carry a number prefix. The Export directory setting in the editor was also removed; it had no effect on drops.

The Mic Select panel is slimmer. The Downmix all and Replay buttons were removed from the panel, the remaining actions share one row, and the page row is hidden for sources with eight channels or fewer.

On macOS, a regenerated waveform no longer covers the Settings or Preset editor windows while they are open.

The Settings About page now shows the SoundPrep version.

SoundPrep is free and open source. If it saves you time, you can support development on Ko-fi: https://ko-fi.com/kuma_pontakuaudio
