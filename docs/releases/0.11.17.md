SoundPrep 0.11.17

Fixed the selected-channel waveform overlay not appearing on macOS when REAPER's GPU acceleration is enabled. The overlay is now drawn in its own window on macOS, so it stays visible with GPU acceleration (Metal) on and no setting change is needed. If the overlay window cannot be used, SoundPrep now shows a notice in the bar explaining the GPU acceleration setting to change.

SoundPrep is free and open source. If it saves you time, you can support development on Ko-fi: https://ko-fi.com/kuma_pontakuaudio
