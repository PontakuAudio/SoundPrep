# SoundPrep 0.11.9 — Remove obsolete distribution files

- Removed the 26 `Audition Macro*.lua` forwarding scripts from the current source tree and ReaPack package. Start **SoundPrep.lua**; optional shortcuts use `SoundPrep - Install actions.lua` and the `actions/SoundPrep - …` scripts.
- Removed the retired ZIP packaging utility and old Python analysis reference implementation from the public source tree. Native analysis remains unchanged.
- Kept only the current release note in the source tree and installed package. Earlier notes and assets remain available in GitHub Releases. Removed the outdated Media Explorer design document; current user guides remain available.

**旧名のアクションを使用している場合:** `Audition Macro` のLuaへ直接割り当てたショートカットは、更新後に対応する `SoundPrep` アクションへ割り当て直してください。すでに `SoundPrep` のアクションを使っている場合、変更は不要です。利用者のAction Listやキー設定を自動で書き換えることはありません。

**Legacy shortcuts:** if a shortcut still points directly to an `Audition Macro` Lua file, reassign it to the corresponding `SoundPrep` action after updating. Existing SoundPrep action paths are unchanged. This update does not rewrite the user's Action List or key settings.

The native helper remains **0.11.6** on macOS and Windows. Its `reaper_audition_macro` filename, the channel-selection JSFX names and persisted internal identifiers remain necessary for loading the helper and existing projects. Original license texts and third-party notices are unchanged.

Quit SoundPrep before synchronizing packages in ReaPack, then launch **SoundPrep.lua** again. Restart REAPER if it requests a restart or replaces the helper.
