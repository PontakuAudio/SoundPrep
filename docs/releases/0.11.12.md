SoundPrep 0.11.12

This speed release lowers idle CPU use and gives new installs zero-wait defaults for inserts and drops.

Changes

- SoundPrep skips rebuilding and resending unchanged selection and waveform state each frame, reducing idle CPU use while you browse Media Explorer.
- On new installs, inserts render only the selected range by default. Source + FX keeps the entire original. Enable "Retain processed audio outside the selected range" to render the audio outside the selection too.
- On new installs, uncached processed drops are placed immediately as editable Source + FX without stopping the timeline for a render. You can bake them any time the transport is stopped with "Render selected drops". To render automatically, enable "Automatically render uncached drops" in Settings.
- This update preserves all existing saved settings.

How to update

Quit SoundPrep and choose "Synchronize packages" in ReaPack. This release uses native helper 0.11.10 on Windows and macOS. If the update replaces the helper or ReaPack asks for a restart, save your work and fully restart REAPER. Then run SoundPrep.lua. Your saved presets and settings carry over.
