SoundPrep 0.11.20

The bar has a new AmbiX toggle. It marks the current file as Ambisonics (AmbiX), remembered per file, and takes priority over the global downmix mode and the automatic filename detection. Marking a file also turns Downmix on. Files whose channel count cannot be AmbiX are refused with a message.

The bar's Mic Select button is now called Select Mics. The Select Mics panel also has a Downmix mode button that cycles Auto, AmbiX and Discrete, so the mode can be changed where the microphones are chosen. Cmd-click (macOS) or Ctrl-click (Windows) on a microphone button now solos that one channel; a plain click still toggles.

If a file's channel count cannot be AmbiX, playback now falls back to a Discrete downmix instead of refusing to play, and the bar status shows that AmbiX is unavailable for the file.

An AmbiX downmix on its own is no longer printed into a drop. The drop keeps the original multichannel media and the decode stays editable in the take; use Render selected drops to bake it. Discrete downmixes of multichannel material, such as 5.1 and 7.1, still print as before.

Switching folders or databases in the Media Explorer no longer changes the preview: the current file keeps playing with its waveform, as in stock REAPER. Selecting another file in the new location switches as usual.

The Normalize target and Monitor level popups on the bar are narrower.
