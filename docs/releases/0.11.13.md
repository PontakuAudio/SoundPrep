## SoundPrep 0.11.13

A fixes-and-polish release for the settings screen and the Media Explorer waveform, from owner testing on Windows.

- **Normalization fade is adjustable**: loudness normalization used to ease toward the measured level at a fixed rate. It now completes over the **Normalization fade** setting (Advanced page, default 500 ms; 0 applies the level at once).
- **Waveform is ready when playback starts**: Media Explorer peaks now build immediately on selection instead of trickling in during playback, so the finished waveform and the playback bar are present from the head of the file.
- **Windows settings screen**: text no longer sits on grey boxes - the App Settings surface is unified, so labels paint directly on the same background as the rest of the window.
- **Defaults are visible and resettable**: every App Settings item now states its default in its help text, and the Advanced page gains a **Reset to defaults** button that restores all settings (the analysis cache folder is not touched).
- **Existing users get the faster render default once**: rendered items now keep only the selected range by default (Insert handles off). The change applies once on first launch; if you turn Insert handles back on afterwards, your choice stays.
- **Auto-render drops is On by default again**: the 0.11.12 change to Off is reverted - with it off, the manual Render control was too easy to miss.
