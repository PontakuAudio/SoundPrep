SoundPrep 0.11.11

This patch keeps SoundPrep running after queued command errors and lets it start in projects with invalid saved Source FX state.

Changes

- If a queued command fails, SoundPrep displays an error message and runs the remaining commands. This applies, for example, when you run Analyse with no file selected or Replay with Media Explorer closed.
- SoundPrep starts even if a take's saved Source FX state is corrupt or comes from an incompatible version. It ignores the invalid state. A take identified as managed only by that state is treated as unmanaged and left untouched.

How to update

Quit SoundPrep and choose "Synchronize packages" in ReaPack. This release uses native helper 0.11.10 on Windows and macOS. If the update replaces the helper or ReaPack asks for a restart, save your work and fully restart REAPER. Then run SoundPrep.lua. Your saved presets and settings carry over.
