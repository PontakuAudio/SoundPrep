SoundPrep 0.11.18

SoundPrep now renders through drops. Use Render selected drops to bake an existing Source + FX drop. The preset tail still applies when rendering with handles.
Removed the standalone Export settings for final normalization, true-peak limiting, and the limiter ceiling.

Waveform peaks for channel selections and multichannel files are now built by SoundPrep's own peak store. Builds are no longer paced, so the waveform completes sooner, and finished peaks are cached for the session, so selecting a file again shows its waveform right away. Very large files (over 200 million samples) keep using REAPER's peak building.

If REAPER refuses to restore an item after a failed render, SoundPrep reports both errors, attempts to restore the remaining items, and closes the undo block. Queued renders also clear their busy flag.
